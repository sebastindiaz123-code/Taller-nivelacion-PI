# Taller de Nivelación PI a PII

Este repositorio contiene la entrega del taller de nivelación de Programación I a Programación II: respuestas teóricas sobre Markdown, Git y Java, además de los ejercicios prácticos de programación en Java.

## Contenido

- **teoria.md** — Respuestas teóricas sobre Markdown, Git y fundamentos de Java/POO.
- **Calculadora.java** — Calculadora básica (suma, resta, multiplicación y división).
- **ContadorVocalesConsonantes.java** — Cuenta el número de vocales y consonantes de una palabra.
- **InvertirCadena.java** — Invierte una cadena de texto ingresada por el usuario.

## Instrucciones de uso

1. Clona este repositorio:
   ```
   https://github.com/sebastindiaz123-code/Taller-nivelacion-PI.git
   ```
2. Entra a la carpeta del repositorio:
   ```
   cd Taller-nivelacion-PI
   ```
3. Compila el ejercicio que quieras probar, por ejemplo:
   ```
   javac Calculadora.java
   ```
4. Ejecúta
   ```
   java Calculadora
   ```
5. Repite los pasos 3 y 4 con `ContadorVocalesConsonantes.java` e `InvertirCadena.java` para probar los demás ejercicios.
